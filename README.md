# PEMSApp - Sistema de Monitoreo de Emisiones Portátiles

Este repositorio contiene la aplicación de software para el módulo PEMS (Portable Emissions Measurement System).

## Estructura del Proyecto

- `backend/`: Servicio API en FastAPI (Python) para adquisición de datos de sensores (LabJack, cámaras, micrófonos, EMG, etc.).
- `web/`: Interfaz de usuario web desarrollada en React + Vite + TailwindCSS.
- `documentacion_pemsapp.md`: Documentación del sistema.
